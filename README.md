# UP-DCC Student Portal

A responsive, browser-only portal prototype for Las Piñas City National Senior High School - Diego Cera Campus.

## Run

Open `index.html` in a modern web browser. The prototype uses plain HTML, CSS, and JavaScript, so it has no install, build, or server requirement.

Use the profile control in the top-right corner to switch between student, teacher, and visitor demo views.

## Included

- Student dashboard, profile and guardian sample record, to-do list, attendance and grade previews
- Courses, sample learning materials, assignment submission flow, and teacher message placeholder
- Teacher classroom tools for posting activities, reviewing sample remedial follow-ups, editing demo scores, and exporting CSV; the illustrative enrollment-by-strand chart is teacher-only
- Limited visitor view with enrollment guidance and public campus information
- Available strands: Engineering, Entrepreneurship, and Tech Pro
- Campus announcements, Guidance and student-safety poster photos, calendar, four-floor illustrative map with the campus evacuation plan, facilities guide with lab-equipment photos, and monthly gallery
- Responsive navigation for desktop and mobile layouts

## Prototype limits

This is a front-end demonstration, not a production student information system. It does not authenticate users, verify teacher IDs, store student records, or provide authorization beyond changing the visible demo role. All names, grades, attendance, enrollment counts, dates, and contact details are fictional or illustrative. Facility floor labels were provided by the user; the map's room positions are schematic and not to scale. Verify school history, official contacts, enrollment requirements, strand offerings, campus maps, calendar dates, and rules with the school before publishing.

Selected assignment files remain in the browser and are not uploaded. Teacher posts and grades exist only in the current page session. Email notifications, parent alerts, messaging, persistent records, and official report cards require a secure backend and school approval. The evacuation plan and other campus photos are provided for the approved school prototype; the interactive floor schematic remains illustrative and is not an official evacuation map. Verify emergency and legal guidance content with school personnel before publishing.
